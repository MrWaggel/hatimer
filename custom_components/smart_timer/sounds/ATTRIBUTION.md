# kitchen-timer.mp3

kitchen timer.wav by KeyKrusher — https://freesound.org/s/154954/ — License: Attribution 4.0

https://creativecommons.org/licenses/by/4.0/

The original recording is a 48 kHz, 16-bit stereo WAV. The file shipped here is
that recording encoded as a 96 kbps MP3 so it loads faster. No other changes
were made.

This sound is the default alarm. It is not mandatory: set the timer sound to
"No sound", or provide your own URL or file, to use something else.
