# kitchen-timer.wav

kitchen timer.wav by KeyKrusher — https://freesound.org/s/154954/ — License: Attribution 4.0

https://creativecommons.org/licenses/by/4.0/

The original file is a 48 kHz, 16-bit stereo WAV. The copy bundled here was
transcoded from the public Freesound HQ preview to 16-bit PCM WAV so it can
ship without a Freesound login. No other changes were made.

This sound is the default alarm. It is not mandatory: set the timer sound to
"No sound", or provide your own URL or file, to use something else.
